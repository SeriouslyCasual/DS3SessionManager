
# Dark Souls III Network Telemetry

A research project investigating real-time network telemetry
and connection quality in Dark Souls 3. 

## Project Objectives

- Investigate Dark Souls III's P2P networking architecture
- Develop a real-time connection monitoring application
- Analyze latency, jitter, and geographic performance
- Evaluate potential network routing improvements

Research and initial development - October 2026

**Expected completion:** December 4, 2026
