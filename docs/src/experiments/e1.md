# E1: Observability map

**Question.** What can a third-party tool observe about Dark Souls III P2P sessions, and how reliably?

## Hypotheses (to confirm or reject)

- **H1.** A second process initialised with AppID 374320 sees the game's sessions through `GetP2PSessionState`. This is undocumented by Valve but used by DS3ConnectionInfo.
- **H2.** Steam reports `m_nRemoteIP` as a host-order integer, so `Ipv4Addr::from(u32)` gives the correct address.
- **H3.** STUN connectivity checks show up as 56-byte requests and 68-byte replies in kernel ETW.
- **H4.** Most sessions are direct (not relayed) unless a player sets Steam's IP-sharing option to restrict sharing.

## Setup

- **PC-A** (main) runs `ds3sm`, elevated.
- **PC-B** is a second PC with its own Steam account. Note its public IP and LAN IP beforehand, from the router or `curl ifconfig.me`.
- Same patch level on both; record the game version from the title screen.

## Procedure

1. **PC-A, before playing:**
   1. Start Steam.
   2. Start DS3 and load a character.
   3. In an elevated terminal, run `ds3sm probe`. Record the output.
2. **PC-A:** start the monitor:
   `ds3sm monitor --label "E1 A<->B direct" --home-lat <lat> --home-lon <lon>`
3. **Co-op:**
   1. PC-B places a summon sign (white soapstone) near a bonfire both players can reach.
   2. PC-A summons PC-B.
   3. Play for 5 minutes.
   4. Dismiss the phantom.
4. **Checks:**
   - [ ] PC-B's Steam ID appears in the table (H1).
   - [ ] The remote IP equals PC-B's public IP, or its LAN IP if both PCs are on the same LAN (H2).
   - [ ] The RTT column fills in (H3). If it doesn't, rerun with other `--req-size` and `--reply-size` values, or do E2 first.
   - [ ] Relay shows `no` (H4).
5. **Relay condition:**
   1. On PC-B, set Steam › Settings › In-Game › *Steam Networking* to the option that restricts IP sharing (record its exact wording).
   2. Restart DS3 on PC-B and repeat steps 2–4.
   3. Expect relay `yes` and a remote IP that is **not** PC-B's.
6. **Public sessions:**
   1. Leave the monitor running during ordinary online play (summoning strangers, being invaded) for at least 30 minutes.
   2. Count sessions: direct vs. relayed, with and without an IP.
7. **Export each run:**
   `ds3sm export --db runs/<file>.sqlite --out <export-folder>/E1/<run> --salt <secret>`

## Same-LAN caveat

When PC-A and PC-B share a LAN, Steam may connect them over LAN addresses, and the RTT will be under 1 ms. That still tests H1–H3. Geographic questions need friends on other networks (E5).

## Record

Keep run notes alongside each export, with:
- game version, Steam client version, Windows build;
- every checklist answer;
- anything unexpected.
